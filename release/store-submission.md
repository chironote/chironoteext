## Store listing

### Description

ChiroNote is a focused clinical documentation companion for existing ChiroNote users. It opens in Chrome's side panel beside the tab where you launch it, so you can record a visit, review the generated note, search recent notes from your ChiroNote account, and copy reviewed text without repeatedly switching tabs.

Features:

- Start, pause, resume, finish, or discard a visit recording
- Choose Standard SOAP, Exam, or Personal Injury note settings
- Follow generation status and review the completed note
- Search recent notes and open a selected note
- Copy a full note or an individual section only when you choose

ChiroNote does not read or modify the EHR page, inject content scripts, or paste automatically. Microphone access begins only after you start recording and approve Chrome's prompt. All executable code is included in the extension package. An existing ChiroNote account and internet connection are required.

## Privacy

### Single purpose

Help a signed-in ChiroNote user record a clinical visit, review generated or recent notes, and explicitly copy user-selected note text into the user's documentation workflow from a Chrome side panel.

### Permission justifications

`sidePanel`:

Provides the extension's compact clinical documentation workspace beside the active tab. The panel lets the user record a visit, review generated or recent ChiroNote notes, and explicitly copy selected text while keeping the EHR visible. It does not read or modify the active page.

Host permissions:

The listed hosts are the specific ChiroNote AWS production services required for the single purpose: Cognito authenticates the existing account and issues temporary credentials; AppSync retrieves notes and receives realtime completion updates; the configured S3 bucket receives user-started microphone audio; SQS queues accepted audio; and the configured Lambda URL requests note generation. There are no wildcard domains, browsing-history hosts, or EHR hosts.

Remote code: **No.** All executable JavaScript is bundled in the package. The extension calls remote APIs for data and processing but does not download or execute remote JavaScript or WebAssembly, reference remote scripts/modules, or evaluate remotely supplied code.

### Data categories

Subscription status is used for account eligibility, but the extension does not collect payment-card or transaction data. It does not read parent-page content or browsing history and adds no activity analytics.

Certify all three Limited Use statements. The published policy states that ChiroNote does not sell extension user data, use it for unrelated purposes, or use it for creditworthiness or lending.
